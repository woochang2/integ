# solidity-narwhal
A simple demonstration of executing Solidity smart contracts in a metamask-enanbled NFT marketplace, using the sui/narwhal as a consensus engine. Ideal for understanding interactions between dapp, contract, geth, and narwhal. 

- [go-ethereum](https://github.com/ethereum/go-ethereum): An AuditChain client for communicating with the AuditChain and end users. AuditChain clients forwards user transactions to validators (i.e., consensus and execution), and mainain the global state by executing blocks that are created and broadcasted by validators. 
- [sui](https://github.com/MystenLabs/sui/tree/main/narwhal): An AuditChain validator which performs consensus and block execution.
- [NFT-Marketplace](https://github.com/BravoNatalie/NFT-Marketplace): An example matamask-enabled DApp.
